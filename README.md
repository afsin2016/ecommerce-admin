# E-Commerce Admin Panel

A React-based E-Commerce Admin Panel for managing products, cart details, orders, and admin dashboard activities.

## Features

- Admin Dashboard
- Product Management
- Add and View Products
- Cart Management
- Order Management
- Product Details Page
- Protected Routes
- Responsive Design
- API Integration using Axios
- Local Storage Support

## Technologies Used

- React.js
- JavaScript
- React Router
- Axios
- Bootstrap
- React Icons
- DummyJSON API
